    📲 Автоматически из уведомлений Kaspi

    Обход без банковского API: телефон пересылает уведомления о покупках в Aqsha, и операции появляются сразу. В конце месяца загрузите выписку — операции из уведомлений сольются с ней без дублей.

    Телефон должен «видеть» Aqsha: быть в одной Wi-Fi сети с компьютером, где запущено приложение (откройте Aqsha на телефоне по адресу вида http://192.168…:8000 — тогда и адрес выше будет таким), или Aqsha должна работать на сервере.

    Android: MacroDroid (бесплатно)
    1. Установите MacroDroid из Google Play и дайте ему доступ к уведомлениям.
    2. Добавить макрос → Триггер: «Уведомление» → «Уведомление получено» → приложение Kaspi.kz.
    3. Действие: «Подключение» → «HTTP-запрос». Метод POST, URL — адрес выше.
    4. Тело запроса — тип «Текст», содержимое: волшебный текст «Текст уведомления» (можно добавить и «Заголовок уведомления» перед ним).
    5. Сохраните макрос и сделайте тестовую покупку — операция появится в «Операциях».

    Вместо MacroDroid подойдёт Tasker или Automate — главное, отправить текст уведомления POST-запросом на адрес выше.

    iPhone: «Команды» + Apple Wallet
    1. Карта должна быть добавлена в Apple Wallet, а платить нужно телефоном или часами.
    2. «Команды» → «Автоматизация» → «+» → «Транзакция» → выберите карту → «Запускать сразу».
    3. Действие «Получить содержимое URL»: URL — адрес выше, метод POST, тело запроса JSON: поле amount = «Сумма», поле merchant = «Продавец».

    iPhone не даёт читать уведомления других приложений, поэтому переводы и оплаты картой без Apple Pay так не попадут — для них остаётся быстрый ввод на вкладке «Операции» и выписка в конце месяца.

    📄 Импорт выписки

    Kaspi: приложение Kaspi.kz → Kaspi Gold → «Выписка» → период → «Поделиться» → сохраните PDF и выберите его здесь.
    Также подходят CSV и OFX других банков. Повторный импорт не создаёт дублей.
