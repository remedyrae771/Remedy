# Remedy 💞

Приложение для пар: работает как сайт в браузере телефона и как мобильное приложение (Expo / React Native). Данные хранятся в **Supabase**, вход по почте и паролю.

## Возможности

- **Приглашение по ссылке.** Один создаёт пару и отправляет ссылку `…/couples/?join=ABC123`. Партнёр открывает её, регистрируется и сразу попадает в пару. Код можно ввести и вручную.
- **Общий питомец.** Котик, щенок, зайчик или мишка, имя выбираете сами. Он радуется, если сегодня вы оба отметили настроение, ответили на вопрос дня и написали друг другу. Если ничего не делать, грустит, а ночью спит. Его можно гладить.
- **Мы:** сколько дней вы вместе, настроение обоих и кнопка «Думаю о тебе».
- **Даты:** годовщины, дни рождения и круглые даты (100, 500, 1000 дней…).
- **Вопросы и игры:** вопрос дня (ответ партнёра открывается только после вашего ответа), игры-карточки, архив ответов.
- **Списки:** общие желания и идеи с отметками в реальном времени.
- **Чат** в реальном времени.

Каждый видит только данные своей пары: это обеспечивают Row Level Security в базе.

## Запуск сайта

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните по очереди `supabase/migrations/0001_init.sql` и `supabase/migrations/0002_pet.sql`.
3. В **Authentication → Sign In / Providers → Email** выключите **Confirm email**, чтобы входить сразу после регистрации.
4. Укажите ключи из **Project Settings → API** (Project URL и anon public key) одним из способов:
   - в `src/config.ts`;
   - или в GitHub: **Settings → Secrets and variables → Actions → Variables**, переменные `SUPABASE_URL` и `SUPABASE_ANON_KEY`.

   Ключ `anon` публичный и предназначен для приложения. Ключ `service_role` никуда не вставляйте.
5. В GitHub: **Settings → Pages → Source: GitHub Actions**. Workflow `.github/workflows/pages.yml` в корне репозитория публикует Aqsha (`docs/`) в корень сайта, а это приложение — в `/couples/`.
6. После слияния в `main` сайт соберётся сам и будет доступен по адресу **https://remedyrae771.github.io/Remedy/couples/**.

## Что внутри (большое обновление)

- **Рост питомца и серии дней 🔥** — питомец растёт (Малыш → Растёт → Подросток → Взрослый → Легенда) за дни, когда заходят оба; на стадиях появляются бантик, ошейник с колокольчиком и корона.
- **Голосовые сообщения 🎤** и **ответы на сообщения ↩︎** в чате.
- **📸 Наши моменты** — все фото и видео из чата плюс воспоминания с подписью и датой.
- **💌 Капсула времени** — письмо, которое партнёр сможет прочитать только в выбранный день.
- **🎯 Кто лучше знает** — один загадывает ответ о себе, другой угадывает, ведётся счёт.
- **Напоминания**: в 9:00 по времени пары — важные даты, годовщина, круглые даты, открывшиеся капсулы; в 20:00 — вопрос дня и «питомец скучает». Функция `reminders` запускается pg_cron раз в час (`0008_reminders_cron.sql`).
- Плавные переходы между экранами и вкладками, появление блоков «лесенкой», анимация новых сообщений.

## Push-уведомления

Партнёру приходят уведомления о новом сообщении, «Думаю о тебе», ответе на вопрос дня и смене настроения.

1. **SQL Editor:** выполните `supabase/migrations/0004_push.sql`.
2. **Edge Functions → Deploy a new function → Via Editor:** имя `notify`, вставьте `supabase/functions/notify/index.ts`, нажмите **Deploy**. В настройках функции выключите **Verify JWT**.
3. В приложении: **⚙️ → Уведомления → Включить**. На iPhone (iOS 16.4+) это работает только из приложения, добавленного на экран «Домой».

Секреты задавать не нужно: ключи VAPID функция создаёт сама при первом запуске и хранит в таблице `push_vapid`, недоступной пользователям.

## Локальная разработка

```bash
npm install
cp .env.example .env   # вписать ключи Supabase
npx expo start         # w — открыть в браузере, или отсканировать QR в Expo Go
```

## Структура

```
src/
  app/                 экраны (Expo Router)
    join.tsx           вход по ссылке-приглашению
    sign-in.tsx        вход и регистрация
    pair.tsx           создание пары / автоматическое присоединение
    (tabs)/            вкладки: Мы, Даты, Вопросы, Списки, Чат
    settings.tsx       питомец, профиль, приглашение, выход
  components/          Pet (SVG-питомец), InviteCard, UI
  lib/                 Supabase, даты, приглашения, настроение питомца
supabase/migrations/   схема БД, RLS, RPC
web/remedy.html        прежняя версия-артефакт для claude.ai
```
